Non-negotiable boundaries

Responsible use is a system property.

The implementation distinguishes analysis limits, blocked capabilities, mandatory human review, and content minimization.

Automatic sending

No endpoint, transport, or UI action can send a message to another person.

Not implemented
Impersonation

Examples are labeled editable drafts; every suggestion requires operator review.

Blocked
Protected attributes

Explicit inference or targeting requests are detected and redirected to relevant documented criteria.

Blocked
Mental-health diagnosis

The engine only describes observable language and never assigns a diagnosis or personality label.

Blocked
Deceptive urgency

Sales guidance permits only real deadlines, constraints, and uncertainty labels.

Blocked
Human judgment

Suggestions expose rationale, evidence, confidence, and limitations before feedback can be recorded.

Required
Raw transcript retention

Ad hoc requests default to no persistence; new retained conversations require a setting, consent, and expiry.

Minimized
Audit contents

Audit records contain state metadata and counts, never transcript text or feedback-note contents.

Content-free
