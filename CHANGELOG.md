# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-30

### Added

- deterministic analysis of momentum, tone, clarity, empathy, unanswered
  questions, and escalation/safety signals;
- explicit sales, support, recruiting, and community coaching modes;
- explainable suggestions with confidence, evidence, limitations, playbook
  references, and mandatory manual delivery;
- responsible-use redirection for manipulation, protected-attribute inference,
  mental-health diagnosis, deceptive urgency, dependency optimization,
  impersonation, and automatic sending;
- FastAPI service with health, conversations, analysis, suggestions, feedback,
  playbooks, metrics, audit, privacy, retention, purge, and reset endpoints;
- SQLite state with a content-minimized audit trail;
- four fictional, fully analyzed scenarios with feedback and outcomes;
- responsive landing page, operator dashboard, animated architecture explorer,
  and guided demo;
- exact publishable static mirror under `site/`;
- tests for deterministic and mode-specific coaching, safety boundaries,
  feedback metrics, privacy, retention, API state, and seed reset;
- MIT-0 release, conduct, contribution, security, architecture, ethics, API,
  demo, deployment, Docker, Compose, scripts, and CI artifacts; and
- consistent local/demo port `8103`.
